# TSL v1 support-file revision baseline

Capture date: 2026-09-10

Status: Slice 0 complete; informational evidence whose compatibility gates
remain owned by typed manifests and executable checks

## Compatibility authority

The reviewed compatibility authority is
[`coverage/tsl-v1-public-api.json`](../coverage/tsl-v1-public-api.json), whose
current schema is version 4. It contains 8,001 exact C++ declaration records
(7,275 stable) and 7,194 exact Rust declaration records (6,978 stable). This
supersedes historical references to the earlier schema-v3 baseline without
changing or re-accepting any API record.

Every generated C++ and Rust project also carries its scope-exact
`public-api.json`. The generation-snapshot command now has two distinct
comparisons:

- `compare` requires identical typed semantics, artifact identities, file
  inventory, and generated bytes for planning or metadata-only revisions; and
- `compare-public-api` compares the complete per-backend declaration records
  while deliberately ignoring physical file layout.

The latter still compares callable signatures, checked/ordinary relationships,
stable type members, aliases and re-exports, reachability, qualifiers,
visibility, safety, and attributes. Strict Doxygen identity validation and
Rustdoc generation remain separate, physical-path-independent gates for
rendered documentation coverage and validity.
