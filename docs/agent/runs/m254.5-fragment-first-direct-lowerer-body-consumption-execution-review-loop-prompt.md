## Goal

Continue the M254.x `ImplementationBody` removal series by migrating direct
selected-body lowering in `Lowerer._lower_direct_body` and its helper
diagnostics toward fragment-derived body tokens when
`Implementation.source_body_fragments` is present.

## Scope

Implement the smallest coherent direct-lowerer ownership slice:

- Add or reuse one narrow selected-body compatibility token view that returns
  body tokens plus source from `source_body_fragments` when present and from
  `ImplementationBody.tokens` only as token-only fallback.
- Route direct operation-fragment detection, `emit_return(...)` detection,
  primitive-call return-payload expression lowering, and unsupported body /
  primitive-call diagnostics through that selected-body token view.
- Preserve accepted binary/unary/comparison scalar lowerer behavior, exact
  `emit_return(call<primitive=...>(...))` behavior, unsupported body
  diagnostics, primitive-call diagnostics, and deterministic results.
- If preserving accepted helper signatures requires a temporary token adapter,
  keep it behind the M254.4 compatibility boundary or one obvious local
  selected-body view. Do not spread new `ImplementationBody` construction.
- Add fragment-backed selected-implementation tests with empty compatibility
  tokens, plus token-only fallback tests where existing tests do not already
  prove fallback.
- Record exact remaining `ImplementationBody` references and use that
  accounting to select the next M254.x prompt.

## Non-Negotiable Guardrails

- No new TSIL keyword semantics or keyword spellings.
- No new operation semantics.
- No primitive-call selector specialization lowering, semantic `@self`
  resolution, or dependency closure.
- No pairwise surrounding-keyword handlers.
- No new parser.
- No backend rendering, build verification, generic loop code generation,
  assignment/index expression parsing, source repair, target-language
  expression/operator parsing, template rendering, CLI work, or template-side
  semantic decisions.
- Do not make `ImplementationBody` more central. Any remaining token path must
  be compatibility fallback, domain/catalog construction debt, or explicitly
  recorded removal debt.
- Do not introduce runtime dependencies on `frozen` or `tslgenold`.
- Do not reactivate M255 while production direct body lowering still depends
  on `ImplementationBody` as the primary source structure.
