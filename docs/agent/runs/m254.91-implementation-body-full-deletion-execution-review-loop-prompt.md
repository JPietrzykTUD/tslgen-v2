## Scope

Implement the smallest coherent full-deletion slice:

- Remove the `ImplementationBody` dataclass from `tslgen.domain.catalog`.
- Replace `Implementation.body: ImplementationBody` with explicit typed body
  fields on `Implementation`, such as `body_tokens: tuple[BodyToken, ...]` and
  `body_source: SourceLocation`.
- Update production construction in `catalog_builder.py` and
  `primitive_project_pipeline.py` to pass the direct fields.
- Update production consumers to read `implementation.body_tokens` and
  `implementation.body_source`; do not keep an `implementation.body` property,
  wrapper, compatibility alias, or replacement class named like
  `ImplementationBody`.
- Update tests and test helpers mechanically so they construct
  `Implementation` with direct body fields instead of importing or instantiating
  `ImplementationBody`.
- Remove or rewrite the compatibility-adapter doc note that names
  `ImplementationBody`.
- Keep `ParsedImplementationBody` parser-layer terminology intact. It is not
  the domain `ImplementationBody` removal target.
- Preserve M254.9 behavior: fragments are authoritative when present;
  token-only fallback remains only for fragment-absent selected
  implementations.
