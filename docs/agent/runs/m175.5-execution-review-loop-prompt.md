## Goal

Support fixed byte-size generation values for:

```text
value<generation>(type::size_bytes(type<generation>(vector::register)))
value<generation>(type::size_bytes(type<generation>(vector::mask)))
value<generation>(type::size_bytes(type<generation>(vector::imask)))
value<generation>(type::size_bytes(type<generation>(vector::mask_underlying_t)))
```

The accepted fixed-size rules are:

- `vector::register`: fixed register byte size is `extension.vector_bits / 8`
  when `vector_bits` is a positive integer.
- `lane_bitmask` masks: byte size is `ceil(lanes / 8)`, where
  `lanes = extension.vector_bits / selected_scalar_bit_width`.
- `same_as_mask_type`: resolve through the mask policy.
- `native_predicate_by_lanes`: use explicit lane-capacity metadata from
  `extension.tsl`; select the exact capacity when present, otherwise the
  smallest declared capacity that can hold the selected lane count. The byte
  size is `ceil(capacity / 8)`.

Scalable, runtime-lane, symbolic-size, missing-metadata, unsupported-policy,
and no-catalog cases must be diagnostics. In particular, do not guess SVE
`svbool_t` or scalable vector register byte sizes.
