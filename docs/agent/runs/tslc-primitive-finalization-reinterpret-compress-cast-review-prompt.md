## What Changed

- Inline implementation body envelopes now use decoded scalar text for
  `payload_text`, while preserving the raw `payload_source` span for
  diagnostics.
- A parser regression covers escaped quotes inside inline TSIL bodies.
- The x86 `reinterpret` `f? -> f?` body now uses the no-instruction bitcast path
  instead of emitting non-existent same-type cast intrinsics.
- The scalar `compress` body now uses `complete(result)` instead of raw
  target-language `return` statements.
- `compress` has an AVX-512VL byte/word fallback that converts native predicate
  masks through `to_integral[Vec]` before testing bits, avoiding `mask<test>` on
  the `native_predicate_by_lanes` representation.
- `CallLowerer` now accepts decimal integer call-bracket entries as forwarded
  template/const arguments, so source calls such as
  `call<primitive=extract[Vec, sse, 0]>(data)` lower through the generic call
  boundary.
- `QueryEvaluator` resolves zero-argument `x86::...` backend value leaves
  through backend translation templates named `value_...`; C++/Rust spellings
  remain in `tsldata/detail/lang`.
- `cast` uses portable array round-trip fallbacks for AVX2 `f32 -> ui32` and SSE
  `f32/f64 -> ?i32` paths where previous bodies used unavailable AVX-512VL or
  SSE4.1 instructions.
- The regenerated coverage inventory reports `reinterpret`, `compress`,
  `cast`, and `convert_down` with `0` skipped slots and `66310 / 67062` lowered
  slots overall.
