## Goal

Create one small shared TSIL lexical boundary helper for already accepted
keyword/classifier code that needs:

- matching outer directive or function-call envelopes;
- splitting payloads on top-level commas while respecting nested
  parentheses, square brackets, and angle brackets;
- finding matching raw brace regions over source-owned tokens;
- tracking raw brace depth only to distinguish top-level token discovery from
  loops/directives inside unrelated opaque raw-brace scopes.

This helper must be lexical only. It must not know what `loop`, `var`, `call`,
`type`, `value`, `if`, or `emit_return` means.

## Design Guardrails

- This is a refactor. It must not change which `.tsl` forms are accepted or
  rejected.
- The helper returns lexical facts such as spans, parts, indexes, or balance
  results. Keyword-specific lowerers/classifiers still own selector names,
  arity, semantic facts, and diagnostics.
- Do not create a broad parser framework, expression AST, statement parser,
  registry, dispatcher, worklist, callback map, hidden backfeed, or fixpoint
  mechanism.
- Do not read `tsldata`, `frozen`, or `tslgenold` at runtime.
- Do not use this refactor to implement M163 variable declaration facts or any
  other new keyword semantics.

- M132-M152 primitive-call classification, selector, argument, resolver,
