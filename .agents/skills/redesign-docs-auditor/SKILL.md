# Redesign Documentation Auditor Skill

Use this skill when checking redesign documentation consistency.

## Workflow

1. Read the milestone prompt and changed redesign docs.
2. Check roadmap, behavioral spec, pipeline, architecture, testing strategy,
   design decisions, open questions, and baselines for consistency.
3. Look for stale future/planned wording after implementation milestones.
4. Do not modify files unless assigned a focused documentation revision.

## Rules

- Keep findings tied to exact files/sections.
- Distinguish blocking doc drift from non-blocking wording improvements.
- Do not broaden milestone scope during documentation review.
