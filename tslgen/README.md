# tslgen

`tslgen` 0.1.0a1 is a narrow alpha / architecture-foundation release candidate
for the clean-room TSL generator redesign.

This package exposes the accepted parser, catalog, validation, selection,
reporting, artifact writer, API/CLI, and narrow C++/Rust rendering slices. It
does not claim full legacy-generator replacement, full TSIL lowering, broad
backend generation, executable generated tests, generated documentation parity,
or drop-in legacy CLI compatibility.

The release scope and exclusions are tracked in
`docs/redesign/stabilization-release-checklist.md` in the repository.
